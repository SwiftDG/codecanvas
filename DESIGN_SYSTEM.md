# CodeCanvas design system

## Direction

CodeCanvas combines the calm density of a precision instrument with the visual rhythm of an independent editorial studio. Marketing pages can be expressive. The coding workspace remains quiet, direct and low-glare.

## Type

- Display: Instrument Serif, used for authored marketing moments and large ideas.
- Interface: DM Sans, used for navigation, actions and general reading.
- Code and state: IBM Plex Mono, used for source, file names, labels and technical feedback.

## Palette

- Ink: `#25261f`
- Paper: `#ecebe3`
- Dark workspace: `#171813`
- Raised workspace surface: `#1e1f19`
- Coral action and syntax accent: `#ef8e72`
- Sage success and output: `#b7cb8b`
- Aqua file and type accent: `#96b8b3`

The palette is based on paper, graphite and drafting markers rather than conventional neon developer branding.

## Layout

- Marketing layouts use asymmetry, strong negative space and section-specific composition.
- Product layouts use compact rails, consistent 1px separators and rectangular controls.
- Cards are not a default container. Information is grouped through alignment, rules and surface shifts.

## Motion

- Motion is limited to directional feedback, panel state and subtle orientation.
- The workspace avoids theatrical movement.
- `prefers-reduced-motion` disables nonessential animation and smooth scrolling.

## Accessibility

- Visible focus rings use the coral accent.
- Primary text and controls maintain strong contrast.
- Icon-only controls include accessible names.
- Core file and run controls remain keyboard reachable.
